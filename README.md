# Friend Note

A friend note plugin for Dalamud.

## Features

- Add, edit, and delete notes for friends.
- Show notes in the friend list as `Character Name (Note)`.
- View existing notes from a target's context menu. This is useful when you see a character name highlighted as a friend but do not remember who they are.

## In-game usage

- Right-click a friend in the friend list and choose the option to add or edit a note. The note will appear after the friend's name in the friend list.
- To remove a note, clear it and save, or delete it from the note list.
- Use `/fnote` to open the note list, where you can edit or delete notes for your friends.
